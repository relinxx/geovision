# GeoVision Imported Map Layers

This directory contains map datasets imported from:
`/geovison/backend/outputs/spatial/befe7e73-4883-4a33-b029-9fb84ecad840`.

Included layers by plan:
- roads
- networks
- blocks
- green
- buildings
- plots
- density

Included zoning/reference layers:
- municipal_boundaries
- zoning_base_sd
- zoning_unincorporated
- general_plan_land_use_sd

Main parcel base map used by the app is copied to:
- `/frontend/public/parcels_env_risk_clipped.geojson`

Layout layer manifest:
- `/frontend/public/data/geovision/spatial/layouts/manifest.json`

Zoning layer manifest:
- `/frontend/public/data/geovision/zoning/manifest.json`
